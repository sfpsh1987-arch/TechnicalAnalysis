### Description
An interactive portfolio dashboard built with R Shiny. It fetches historical
stock data from Yahoo Finance (quantmod) and visualizes it with ggplot2:
- Line chart of closing price with date-range and time-frame (Daily/Weekly/Monthly) filters
- Moving Averages (20/50) overlay
- RSI (14) and MACD panels with toggle checkboxes
- MA-crossover trading rules annotating Buy/Sell signals at crossover points

### How to run
1. Install the required packages: `shiny`, `ggplot2`, `quantmod`
2. Open `ASSIGNMENT6.R` in RStudio and click **Run App**
